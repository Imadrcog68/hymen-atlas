HYMEN ATLAS — FREE WEB APP

1. Unzip this folder.
2. Create a free account at github.com.
3. Create a PUBLIC repository named hymen-atlas.
4. Upload ALL FILES from inside the hymen-atlas folder, including images/ folder.
5. Go to repository Settings > Pages > Deploy from a branch > main / (root) > Save.
6. Wait for the published HTTPS link (usually https://USERNAME.github.io/hymen-atlas/).
7. Open that link in iPhone Safari > Share > Add to Home Screen.
